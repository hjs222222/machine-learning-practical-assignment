# 二、数据分析成果展示

## 子任务1：字段中文含义

数据集包含1827天（2000-2004年）的逐日观测数据，共9个字段。所有字段的中文含义如下：

| 英文字段 | 中文含义 | 单位 |
| --- | --- | --- |
| Date | 日期 | - |
| Discharge | 径流（流量） | ft³/s |
| Dayl | 日照时长 | s/day |
| Prcp | 降水量 | mm/day |
| Srad | 短波辐射 | W/m² |
| Swe | 雪水当量 | kg/m² |
| Tmax | 最高气温 | °C |
| Tmin | 最低气温 | °C |

## 子任务2：时间序列可视化

对流域数据集的所有列（日期除外）进行了时间序列可视化，包含径流、降水、气温、辐射等8个变量的完整时间序列。

## 子任务3：直方图

对所有变量绘制了分布直方图，展示各变量的统计分布特征。径流和降水呈明显右偏分布，气温类变量接近正态分布。

## 子任务4：箱型图

箱型图分析显示径流的离散程度最大，存在大量高值异常点（洪水事件）。按月分组的箱型图展示了明显的季节性特征。

## 子任务5：皮尔逊相关系数热力图

完成了三类相关性分析：

1. 径流序列与其自身滞后序列的相关系数（自相关ACF）

2. 径流序列与其他因子同期序列的相关系数

3. 径流序列与其他因子滞后序列的相关系数（互相关CCF）

降水（Prcp）与径流的同期相关性最强（r=0.43），其他气象因子与径流的线性相关性较弱，说明需要引入滞后特征。

径流的自相关系数lag1为0.77，lag7为0.40，衰减较快但仍有明显记忆效应，为引入滞后特征提供了依据。

# 三、特征工程成果展示

## 子任务6：时间序列特征提取

完成了三类时间序列特征提取：

1. 季节与月份编码

• 四季编码：season_春/夏/秋/冬（one-hot编码）
   • 月份编码：doy_sin, doy_cos, month_sin, month_cos（三角周期编码）
   共8个特征

2. 滞后特征（Lag Features）

• 变量：Discharge, Prcp, Tmax, Tmin, Vp, Srad
   • 滞后阶数：1, 2, 3, 7, 14, 30天
   共36个特征

3. 窗口特征（Rolling Features）

• 变量：Discharge, Prcp
   • 窗口长度：3, 7, 14, 30天
   • 统计量：mean, std, max
   共24个特征

总计构造81个候选特征

## 子任务7：特征归一化

实现并对比了两种归一化方法：

• 最小-最大归一化（Min-Max Normalization）：将特征线性映射到[0,1]

• Z-score标准化：将特征转换为均值0、方差1的分布

经对比，Z-score标准化对异常值更稳健，更适合本数据集的强右偏分布特征，因此最终采用Z-score标准化方法。

## 子任务8：特征选择

实现并对比了两种特征选择方法：

• 皮尔逊相关系数法：度量特征与目标的线性相关性

• 互信息法：基于信息熵，能捕捉非线性依赖关系

互信息得分最高的是径流自身的短窗口与滞后特征，说明径流的近期状态是最强的预测因子。最终按互信息得分保留TOP 50个特征。
