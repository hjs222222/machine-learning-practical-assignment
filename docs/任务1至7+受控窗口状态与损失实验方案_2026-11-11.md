# 任务1至7：受控窗口、历史状态与损失实验方案

日期：2026-11-11。用途：项目维护者的训练执行记录；本轮是小规模因果消融，不替换现有正式验收报告。

## 1. 目标和边界

依据[全面诊断](diagnostics/20261111_full_review/README.md)，本轮回答两个问题：

1. 相同容量下，30→90天历史、增加历史状态，是否带来跨年稳定改善？
2. 在仅由历史内层选定的输入上，log/sqrt/raw损失有何差异？

先运行direct h1、direct h7和原生七输出三个任务；未实施direct h2～h6、ANN/RF替换或新的融合，不能称为完整七任务交付。固定三个seed42/43/44，不按结果挑seed。

仅用课程CSV。读取完整文件核验字段/日期，但构建模型数组前删除2004全部行；不读取任何2004预测，不使用外部气象。2004既已被历史查看，即使未来回溯也不称独立盲测。

## 2. 按日期建立独立输入，避免改坏历史流程

新代码直接从原CSV构建独立dataset，不修改已有prepare_v2或任何冻结run。字段白名单、日期连续唯一、有限数值、正Q和非负P均先校验；不接受额外目标字段。

- 起报t，目标t+1～t+7；所有状态只读取截至各特征日的信息。
- 状态需90天预热；为使所有窗口覆盖完整有效状态，统一从CSV第179行起报，即2000-06-27。
- 截至2003-12-31共1461日，1276个共同起报点。各方案使用相同训练/验证id，不把少丢样本的收益混进窗口对比。
- x scaler使用当前训练id覆盖的90日历史行并集；所有方案相同、不含未来行。这是预注册的历史缩放范围，30日方案也使用这组合法历史统计量。
- 数据不做路径全局缓存；恢复模型严格核验dataset hash和特征布局；id必须是有效整数。

## 3. 输入和网络：2×2对照

| 名称 | 窗口 | 历史状态通道 |
| --- | --- | --- |
| w30_base | 30日 | 固定置零 |
| w90_base | 90日 | 固定置零 |
| w30_state | 30日 | 使用 |
| w90_state | 90日 | 使用 |

基本9列：Q(t)、Prcp、Tmax、Tmin、Vp、Srad、Dayl、日序sin/cos。

状态8列：P_sum7/30/90、API095、Q_change1/7、Q_mean30/90。API按API(t)=0.95×API(t−1)+P(t)，从CSV首日零状态递推，衰减率预固定，不依据外层成绩调整。这些只是因果代理，不叫实测土壤水分。

Q、P与8个状态列使用固定signed_log；温度、气压、辐射、日长、周期列保留原值后StandardScaler。与此前诊断的全部列signed_log不同，本轮只在同协议方案之间作因果比较。

所有方案均17输入通道。base方案的8状态通道在缩放后置零，保证参数量和同seed初始化完全相同；未声称置零网络与删列网络具有相同正则效应。

固定：单层LSTM32、dropout0.1、统一32维head、Adam、lr0.001、batch64、顺序批次、梯度裁剪1，无持久性残差/weight decay。单输出和多输出仅最后输出维度不同。不使用MultiOutputRegressor。

## 4. 验证和选择，运行前固定

- 外层：2002年、2003年，各358个起报点；当年h7必须不晚于12月31日。训练所有h7标签严格早于当年1月1日。
- 每外层仅用其训练历史末尾连续3块90日起报作为内层验证。每折训练h7目标严格早于验证首起报，净化7日。2002外层训练546样本，内层训练269/359/449；2003外层训练911样本，内层训练634/724/814。小内折样本有限，结果需保留这一局限。
- 每seed/方案用GridSearchCV选固定epoch：10或30；基于原尺度逐h RMSE平均，不以训练loss排序。
- 1%范围内近似平手选更少epoch。这是本轮预注册简化规则，不是用户新增指标门槛。
- 输入方案按三个seed的**内层**分数平均选择，1%范围内按w30_base→w90_base→w30_state→w90_state优先。外层结果不参与选择。
- 三块主要覆盖此前一年的后三季度，季节代表性有限；不声称覆盖所有季节，也不因看到外层成绩更换这组折。

阶段一：4种输入、固定log损失。

阶段二：在阶段一内层选出的输入上比较sqrt/raw；log模型直接复用。保持网络、初始化、优化器、特征变换与epoch候选相同；各损失仍仅由内层选epoch。输入可能随外层年份不同，不按外层结果改配置。此次不实现混合损失，避开旧raw+mixed_weight的条件性缺陷。

本轮比较的是“相同搜索预算下的输入/损失方案”，不是固定训练轮数的纯梯度轨迹消融：各方案最终epoch可以不同。若有稳定收益但需要区分表示和预算的贡献，后续应另加固定epoch对照，不能将本轮全部差异只归因于窗口或损失。

sqrt逆变换固定max(z_raw,0)²；log为exp(z_raw)；raw不截断负预测，照实计数。不事后根据评价误差更换逆变换规则。

正式run计划：formal_20261111_controlled_v1。运行目录保存独立dataset、源码快照/hash、每次fit历史、CV、选择记录、逐h指标、逐行预测、全部外层权重和scaler；每模型保存后立即恢复重建预测。完成后另以[独立核验器](../code/verify_runoff_controlled.py)核验，不以脚本退出0代替数值核验。

比较：固定输入log的窗口/状态配对，以及内层选择输入后的三种损失。年度和季度分别保留；对7/14/30日块长做配对重采样敏感性，seed不按独立日样本堆叠。其区间只反映现有年份的相关误差不确定性，不证明跨流域或未来年份泛化。区间、最差seed/季度与平均指标共同报告，不用2004补筛。
