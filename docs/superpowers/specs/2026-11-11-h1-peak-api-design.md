# 第一天精度：API/动量特征 与 洪峰加权 对照设计（2026-11-11）

## 目标与范围

用户授权执行两条训练期对照，验证能否提高第一天（h=1）测试精度，不替代教师必做模型：

- **A：特征增强**——在 91 列基础上加入前期降雨指数（API）、显式流量差分（动量）、昨日及更早降雨累计，重跑 RF/ANN。
- **B：洪峰加权**——训练时放大高流量样本权重，重跑 RF/ANN。

只用教师 CSV 的 2000—2003 年，2004 不构造、不评分。教师规定的 24 基模型 + 16 集成模型、两种策略、前四年训练第五年测试全部保留；本实验是补充研究。

## 为什么选这两个（诊断依据）

训练期（2000—2003）原点可得特征与 Q(t+1) 的 Pearson 相关：Q(t)=0.777；API(α=0.9)=0.409；Prcp 14 天累计=0.346；Prcp(t)=0.329；Q(t)−Q(t−1)=0.290。次日 Q>2000 的 100 个事件日，原点 Q(t) 已达全体 5.77 倍、动量正向、Prcp(t) 3.24 倍。当前 91 列不含 API、显式差分、昨日及更早降雨累计，树模型无法自行算差分，故补入这些特征。

## 门槛与判定（读成绩前固定）

统一在 2002/03 两年共 716 天比较（沿用三路线批次口径）。候选相对**同协议内部对照**：

- A（RF_api/ANN_api）相对 RF_mi / ANN_mi；
- B 的 RF_peak* 相对 RF_mi；ANN_torch* 相对 ANN_torch1（后端相同，唯一差异是 peak_weight）。

资格门槛（沿用既定规则）：合并 R² 至少提高 0.01；2003 R² 不得降低超过 0.005；2002 R² 不得降低超过 0.01；合并 MAE 不得增加超过 1%。任一候选达标才视为晋级，进入冻结与单独授权的 2004 回溯；本轮不自动打开 2004。
