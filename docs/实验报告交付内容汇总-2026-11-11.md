## 1. 实践报告：必备章节与对应要求

指导书的"任务流程"就是报告的骨架（① 一/二/三节）。下表左列是章节，中列是老师原话，右列是报告里必须看得见的东西。

### 第一部分 数据分析（① 一）

| 报告小节 | 老师要求 | 必须出现的内容 |
|---|---|---|
| 1.1 数据来源与字段含义 | "理解所用数据集的各个英文字段的中文含义"（① 一.1） | **字段对照表**：CSV 每个英文字段 → 中文含义 → 单位。出处为 Daymet 文档 Table 1（⑤ 明确指向 `Daymet_Daily_V4R1.pdf` 的 Table 1） |
| 1.2 时间序列可视化 | "时间序列数据可视化"（① 一.2） | 流量/降雨随时间变化曲线图 |
| 1.3 直方图 | "直方图"（① 一.2） | 各主要变量的分布直方图 |
| 1.4 箱型图 | "箱型图"（① 一.2） | 箱型图，用于说明异常值与离群点 |
| 1.5 皮尔逊相关系数热力图 | "皮尔逊相关系数热力图"（① 一.2） | 热力图 + **对强相关项的解读**（不是只贴图） |
| 1.6 分析结论 | "深入了解数据分布及相关性等情况"（① 一.2） | 用文字写出：分布形态、季节特征、哪些变量与径流强相关 |

> ④ 特征工程 PPT 有两句话可直接引用进报告作为立论：
> "数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限。"
> "垃圾进，垃圾出（Garbage in, garbage out）。"

### 第二部分 特征工程（① 二）

| 报告小节 | 老师要求 | 必须出现的内容 |
|---|---|---|
| 2.1 季节与月份编码 | "对四季和月份进行编码"（① 二.1） | 说明编码方式。④ 指出月份编码的关键：**"1 个月份变量，变成 2 个连续特征"**（正弦/余弦），报告里要解释为什么不用 1–12 的整数 |
| 2.2 滞后特征 | "提取滞后特征"（① 二.1） | 明确写出滞后阶数，如 t−1、t−2、t−3、t−7、t−14、t−30，并说明选择依据 |
| 2.3 窗口特征 | "提取窗口特征"（① 二.1） | ④ 点名的统计量必须齐：**平均值、中位数、标准偏差、最小值、最大值**。缺一个都算漏 |
| 2.4 归一化方法总结 | "**总结**常用的特征归一化方法"（① 二.2） | 方法综述：Min-Max、Z-score 等，各自公式、适用场景、优缺点。④ 给了对比结论：**Min-Max 对异常值不稳健，Z-score 更稳健** |
| 2.5 归一化实现 | "**实现**最小-最大归一化或 Z-score 标准化方法"（① 二.2） | 二选一实现 + 代码/结果。报告必须写明一条纪律：④ 原文 **"对测试集独立归一化是常见错误之一！"** —— 归一化参数只能在训练集上算 |
| 2.6 特征选择方法总结 | "**总结**常用的特征选择方法"（① 二.3） | Filter / Wrapper / Embedded 三类都写到（④ 有定义，可直接引用） |
| 2.7 特征选择实现 | "**实现**皮尔逊相关系数法或互信息法"（① 二.3） | 二选一实现。另需说明多输出下的选择策略（见下） |

**多输出策略下的特征选择是单独考点**（③ 第 12 页）：

> 模型仅有一个但输出有多个时，三种做法：
> （1）**交集**：每个输出分别选特征，取交集；
> （2）**并集**：每个输出分别选特征，取并集；
> （3）**共用**：只针对 t+1 选特征，其他输出共用。

报告里至少要说明用了哪一种、为什么。

### 第三部分 径流预测（① 三）

| 报告小节 | 老师要求 | 必须出现的内容 |
|---|---|---|
| 3.1 方法调研 | "调研适用于径流预测的机器学习、深度学习**和集成学习**方法"（① 三.1） | **文献综述**——这也是凑够 ≥6 篇参考文献的主要来源。② 给了可写的分类：机器学习（线性回归、KNN、ANN、决策树、SVM、随机森林、XGBoost）、深度学习（LSTM、CNN、TCNN、CNN-LSTM、Transformer、GRU、GNN）、水文模型（新安江、SWAT、VIC 等） |
| 3.2 数据划分 | "前4年训练，第5年测试，**按时间顺序切分，不能打乱**"（① 四.4、⑤） | 明确写出训练/测试年份与划分方式，并说明为什么不能随机打乱（避免用未来数据"预测"过去） |
| 3.3 两种预测策略的定义 | "多步直接预测和多输出预测两种方式，预测未来 1–7 天"（① 三） | 各画一张示意图（② 有多步递归/直接/多输出的对比图可借鉴），并说明**为什么本实验只用这两种、不用递归** |
| 3.4 ANN 模型 | ① 三.2：(1) 直接策略 (2) 多输出策略 (3) **Grid Search CV** (4) 评价精度 | 4 项逐一交代，含网格搜索的取值范围与最优参数 |
| 3.5 随机森林模型 | ① 三.3：同上 4 项 | 同上 |
| 3.6 LSTM 模型 | ① 三.4：同上 4 项 | 同上（深度学习，需写明网络结构、层数、训练轮数、早停） |
| 3.7 集成学习：简单平均 | ① 三.5：两种策略下各构建一次 | Stacking 与简单平均都要**分两种策略**写 |
| 3.8 集成学习：Stacking | ① 三.5：同上 | 需交代元学习器是什么、如何避免信息泄漏 |
| 3.9 模型数量核对 | "个体模型 3×8=**24**，集成模型 2×8=**16**"（① 四.2、四.3；② 亦有） | 报告里放一张**模型清单表**，逐一列出 24+16=40 个模型，证明没有缺项 |
| 3.10 评价指标与逐预见期结果 | "**分别计算不同预见期下的径流预测精度**"（③ 第 13 页） | 指标定义（R²/RMSE/MAE）+ **h=1…7 逐天的指标表**，不能只给一个综合值 |
| 3.11 结果对比与分析 | ① 三.5(3)"评价模型精度" | 各模型横向对比、两种策略对比、与基线对比，并解释差异 |

## 3. 思政报告（单独一份）

出处只有一句：② 课程要求 —— "提交电子版实践报告、**电子版思政报告**、工程代码"。没有字数与格式规定。

可写什么，⑥ 表3《课程思政教学设计》给了 5 个思政元素，正好对应本项目的 5 个环节：

| 思政元素 | 大纲给出的落点（⑥ 表3） | 本项目的具体素材 |
|---|---|---|
| **创新思维** | 通过问题分析与任务分工，引导科学探索精神与创新思维，培养团队合作意识 | 在教师要求之外自选改进方向（多输出策略选择、集成方式对比） |
| **忧患意识** | 通过文献调研了解国内外差距，激发忧患意识、爱国主义使命感与责任心 | 径流预测的防洪抗旱意义；国内新安江模型的世界影响力（② 有专门一页讲赵人俊团队） |
| **团结协作** | 小组协作中充分沟通、紧密协作 | 3 人分工：数据分析 / 特征工程 / 模型与集成 |
| **工匠精神** | 代码编写、调试过程中精益求精 | 可写：为保证时序不泄漏而坚持按时间切分、对每一处指标做独立复算 |
| **实事求是** | 独立完成、不抄袭，培养诚信精神与实事求是的科研精神 | **这一条最有写头**：如实报告未达到预期精度，不修改测试集、不在测试集上反复挑模型 |

> 最后一条建议重点写。本项目在测试集精度上的处理（配置冻结后才评价、只评一次、不达标就如实报告）恰好是"实事求是"的实证材料，比空泛表态有力得多。
