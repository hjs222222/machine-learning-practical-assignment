# 任务1至7：第一天R²专项目标与方案

日期：2026-11-11。用户明确把第1天R²作为主标准，目标至少0.8。本轮据此开展专项训练；0.8是目标而非已达结果，不保证可达，不把历史某年的高分冒充2004成绩。

## 1. 当前起点

同一2004年359个起报点上：原正式direct LSTM三seed平均R²约0.4733，最新内层冻结所选残差LSTM为0.4086。原正式direct RF/Mean/Stacking的三seed平均也仅约0.50，不能只换成RF就声称满足0.8。

上一轮损失实验只在历史评价，未新增2004成绩。2002年第1天R²0.8802和2003年的0.4699表明跨期差异很大。不能选择2002或最好seed作为验收成绩。

## 2. 新假设和评价

- 优先让模型直接利用当日Q及近几日升退水趋势，并预测原始尺度增量Q(t+1)−Q(t)，用固定Q(t)跳连恢复输出。不同于前轮log输出头/exp逆变换，允许线性增量表达，不事后裁负值。增量按训练均值/标准差缩放，ANN/LSTM零输出头的初始预测为Q(t)+训练增量均值，并非严格Q(t)持久性；网络无dropout。
- 用更覆盖季节的四块历史内层验证，并以共同验证日期的合并R²选择配置，避免简单平均各折R²过度强调低方差季节。GridSearchCV记录逐折R²与直接计算的SSE（不用折内R²反推，避免常量折漏算误差），合并R²=1−合计SSE/合并验证真值SST；各候选使用同一日期，等价于最小化合计SSE。
- 仍只用截至t已观测Q和气象，不平移日期，不输入未来真实降雨，不下载外部数据。所有外层选择只使用当年之前的数据，scaler只fit内层训练。

## 3. 固定候选与预算

共同复用controlled历史数组、90日预热与1276个合法历史样本；训练边界保守沿用h7净化，评价仍是h1。输入来自同一历史，可分两路但不混称严格单因素比较：

1. Ridge增量趋势基线：alpha10/1000，两候选。
2. RF增量：200树，depth10，leaf2/10，两候选。
3. ANN增量：32隐藏单元，epoch30/100，两候选。
4. LSTM增量：32隐藏单元，window7/30，epoch10/30，四候选。

共10个预固定配置。Ridge/RF/ANN使用明确的因果tabular趋势输入：Q(t)及lag1/2/3/7、差分、7/30/90日均值、降雨当日/近3/7/30日和、当日气象/日序。LSTM使用9基础通道的短窗口，另将相同tabular向量连接到32维head，含原始Q和趋势快捷路径。基线/表格模型与LSTM输入形式/容量不同，属于完整方案比较，不把收益全归因于某个结构。

seed42/43/44全部保留。每个年份/候选/seed四折内层搜索并从零外层拟合；2002和2003共2×10×3×(4+1)=300fit、60个保存模型。四折各90个验证起报，位于当年训练历史末尾360日起报；最低训练150样本，最远h7目标严格早于验证首起报。

预检仅seed42、四候选（各族第一个，树5/epoch1），共40fit、8模型；不得改标正式或作效果证据。固定线程，GPU用于神经网络、CPU用于Ridge/RF，可在同一命令串联，不争抢多个GPU训练。

每个模型族按三seed合并内层R²均值选择配置；差异不超过0.005时按上列简单候选顺序取优先项。另从四模型族中按同规则选择总体冠军。全部2002/2003选择先冻结hash，再拟合外层，保留全部候选，不从外层挑冠军。

历史推进门槛：2002/2003的内层所选LSTM各年平均R²均不低于0.70且较旧同年度所选log残差至少增加0.02；每年不少于2/3 seed改善，MAE退化不超过10%。总体冠军和其他模型另报，不替代LSTM门槛。0.70仅是值得推进的开发门槛，不是把用户0.8目标降低：最终达标仍须同一2004样本的第1天R²≥0.8，报告三个seed均值和每seed，不挑seed。
