日期：2026-11-11。供项目维护者决定后续训练；不是新的正式验收报告。

本轮只包含direct h1、direct h7、原生multi三个哨兵任务。全部评价止于2003年；没有2004新成绩。

## 1. 执行与独立核验

- 正式完成756次fit、108个外层模型。
- 已恢复全部模型，核对115992行预测和324项逐h指标；核验状态：passed。
- 共同起报样本、固定17通道和32单层LSTM、三个seed；窗口/状态比较统一log损失。
- 为保证90日状态和90日窗口完整预热，起报从2000-06-27开始，比旧30日工程序列更晚；不能把本表直接与旧run数字当配对提升比较。
- 训练预算仅由各外层历史内层的3块90日GridSearchCV选择10/30轮，1%近似平手选少轮数。
- 输入按三个seed内层均值选择；不同年度可选不同输入。外层只评价，不用于换输入。

## 5. 解读边界

这里不同输入、损失和年度的平均数属于开发对照，不是额外独立测试。不将某个最佳seed、最佳h或最佳季度拼成新模型；不把本轮结果归因于单一水文机理。

状态是固定API/累计雨量/流量统计，未重建真实积雪或土壤水分；90日也不等于覆盖所有长期状态。若提升不稳定，应保留失败证据，再设计新的小对照，而不是用2004继续筛选。

本轮未改变ANN/RF、未重新训练Mean/Stacking、未完成direct h2～h6，不能据此宣布全部七项任务已提升。原CSV、历史run、正式Word保持不变，未提交或推送。
