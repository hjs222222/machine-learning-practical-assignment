本课题根据流域逐日径流和气象观测，预测未来1—7天的径流，属于监督学习中的时间序列多步回归任务。输入为预测原点t当天已观测值及其历史，输出为t+1至t+7的流量。

实验依次完成数据分析、因果特征工程、人工神经网络/随机森林/LSTM建模、简单平均与Stacking集成。三种基模型各构建七个直接模型与一个七输出模型，共24个；两类集成共16个。全程只使用教师CSV。

正式回溯测试的最高h=1 R²为0.5103（multi/RF），RMSE为589.20，MAE为194.99。本次未达到约0.8目标。所有结果以原始流量尺度报告，不将相关系数平方替代R²。





训练数据为2000—2003年。为保证七步标签全部留在训练期，训练预测原点最晚到2003-12-24。正式测试预测原点为2004-01-01至2004-12-24，共359行。每行标签为未来1—7天，同一原点同时用于所有策略。2004年内较早日期的已观测径流可作为随后原点的输入，这是滚动预报，不是用测试标签拟合模型。

开发采用两折TimeSeriesSplit，gap=7。Stacking采用三折外层OOF，每个外层训练段再独立两折网格搜索。训练标签最晚日期必须早于验证起点。每次fit重新计算互信息、缩放和模型参数；验证与测试不参与这些统计。

网格搜索和目标变换

训练期先导搜索显示h=1验证R²约0.67—0.69，随后加入相对当天已知径流的残差候选。目标候选为原始值、平方根和log1p；残差方案在相应目标尺度预测相对Q(t)的变化，再逆变换恢复流量。最终模型均由冻结网格决定，测试结果不反向影响选择。

ANN为单隐层MLP；RF使用120棵树并搜索叶节点最小样本数；LSTM为单层循环网络、线性输出头和Adam优化器。七输出网络不是七个独立包装器。LSTM以purged CV选择30或70轮训练，不采用随机验证集早停。



正式预测与集成结果

R²=1−Σ(y−ŷ)²/Σ(y−ȳ)²；RMSE为均方误差平方根，MAE为绝对误差均值。R²允许为负数，不截断也不将其改为相关系数平方。所有预测通过相同非负约束处理，指标保持原始尺度。

简单平均对三个基模型原尺度预测等权平均。Stacking仅用训练期嵌套OOF预测拟合Ridge；直接策略每h三列元特征，多输出为21列基预测到七个目标。两种集成均为实际生成结果，未退回单模型代替。

持续性基线与误差分析



正式h=1最高R²模型的20个最大误差日占其平方误差总和的91.1%。该统计只用于冻结后的解释，未用来重选模型。极端值被保留；若模型对少数洪峰误差较大，R²与RMSE会明显下降，MAE则相对不敏感。



日期与多步标签边界：起初的实现需求只写按年份切分，不足以证明七步标签未跨界。先写因果与日期失败测试，再实现训练标签截止日断言、gap=7和359个共同测试原点，边界测试通过。

输入/输出一致性：为ANN、RF、LSTM分别编写原生七输出、单输出列形状、训练折缩放和序列化恢复测试，确认预测矩阵与实测日期对应。残差扩展先由失败测试暴露不支持参数，再验证在零变化目标下能重构当天流量。

ANN收敛：快速单元测试故意只运行10轮，会出现ConvergenceWarning；正式训练的警告数量记录在每个搜索JSON中，不隐藏为已完全收敛。网格预算固定，未在正式测试后追加轮次。

正式96组搜索累计记录37条收敛警告（含未胜出的候选和OOF内搜索），说明有限预算下部分ANN候选未充分收敛。它们是优化预算限制，不能据此把测试分数解释为理论上限。

文档转换：打包渲染器缺少LibreOffice可执行文件，已记录错误。改用Microsoft Word转换教师.doc副本并导出PDF，通过逐页图像检查报告版面；没有改变教师原文件。

使用技术：pandas日期索引、numpy序列、matplotlib可视化、Pearson分析、月份正余弦/季节one-hot、滞后/滚动、互信息、Z-score、MLP、随机森林、PyTorch LSTM、GridSearchCV、purged TimeSeriesSplit、嵌套OOF、Ridge Stacking和Git版本记录。

本次全部模型最高h=1 R²为0.5103。未实现约0.8的性能目标，应将这一点作为结果限制，而不是用训练分数替代测试分数。预见期越长，可用历史对未来的解释力可能下降，但不强迫指标单调。

当前限制包括四年训练数据较少、气象只截至t、有限网格和单随机种子。后续如有新的合法独立数据，可预先设计验证期，再研究更多历史窗口、洪峰加权损失或多种子稳定性；本次不能用2004结果继续选参。由于2004已在旧实验查看，本次属于冻结配置后的回溯评价。
