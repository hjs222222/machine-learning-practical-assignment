# 机器学习课程实践工程代码

本包提供正式运行 `formal_20261105_clean` 对应的 Python 源码、匹配的测试、依赖和图表分析入口。正式运行源码与 Git 提交 `d7d5f34d821d746cc622fe0bcc9178c2106db86f` 逐文件一致。报告、原始数据、训练权重和历史研究脚本不在本代码包内。

## 目录

- `code/`：正式运行的 8 个源码文件，入口为 `code/run_all.py`。
- `tests/`：与正式源码同期的 5 个测试文件。
- `report code/final/analyse_run.py`：在完整正式运行后生成报告图表的入口。
- `requirements.txt`：本项目环境依赖版本。
- `提交清单.json`：数据、配置与包内文件的 SHA-256。

## 准备与运行

环境：Windows、Python 3.13.5、Git；依赖版本见 `requirements.txt`。在解压后的本目录执行：

```powershell
python -m pip install -r requirements.txt
```

教师原始数据**不在压缩包内**。请将课程提供的 `01047000.csv` 放入 `Teacher Resources & Requirements/01047000.csv`，保持原文件不变，其 SHA-256 应为 `ab09410b23118510bb4e8787a62b97693336a1c46477a01329f587c64bc57151`。此路径由代码唯一指定，不从其他位置或网络补数据。

放好数据后，先运行测试与训练期短跑：

```powershell
python -m pytest tests -q
python code/run_all.py --benchmark --name benchmark_1
```

如需从零复现正式流程，使用**尚不存在**的新目录名；完整训练包含 24 个基模型、16 个集成模型及嵌套网格搜索，耗时明显长于短跑：

```powershell
python code/run_all.py --name formal_reproduction_1
python "report code/final/analyse_run.py" output/formal_reproduction_1
```

输出写入 `output/目录名/`，目录已存在时程序会拒绝覆盖。PyTorch 可使用 CUDA 或 CPU；设备与依赖差异可能造成浮点结果细微变化。2004 年在项目研究中已被查看，报告结果属于冻结配置后的历史回溯，不是全新盲测。不要把训练期分数写成正式测试分数。
